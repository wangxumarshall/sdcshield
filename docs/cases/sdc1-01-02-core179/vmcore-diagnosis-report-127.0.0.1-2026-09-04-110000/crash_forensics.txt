===== neon_rot_ldr_at 业务解读 =====
ps 实测: 191 个 neon_rot_ldr_at 进程(每CPU一个, PID 58051+, 父进程 57625 opendcdiag ← bash(57622)← init)
opendcdiag 是 openEuler/鲲鹏平台的内存在线诊断工具, 其负载生成器会派生每-CPU NEON 压测进程
neon_rot_ldr_at 名字直译: NEON 旋转/循环 load 地址测试 —— 正是负载通路的压测程序
LOAD AVERAGE 15.67 (1min) 也与 191 CPU 满载后短暂调度回落的状态吻合

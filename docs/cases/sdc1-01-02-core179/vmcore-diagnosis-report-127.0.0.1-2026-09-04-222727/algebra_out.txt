  字节序列(MSB..LSB) = 00 ff ff d4 81 23 27 c0

  = (0xffff6040xxxxxxxx/0xffff6057xxxxxxxx) - 0xffffab7f5de796c0

8. 微架构定位: 读路径, CPU179 私有层级
==============================================================================
(a) 全部 5 个事件均为 WnR=0 读错误(数据读 + 页表走查读)。
(b) 破坏为间歇性(非持久): W1..W4 之间系统正常运行 40s; 若 PGD 持久损坏会连续故障。
(c) 全部发生在 CPU179; 崩溃案跨 4 次开机均为 CPU179。
(d) __per_cpu_offset 位于内核 .data(共享 DRAM), 各 CPU 读同一行; 若 DRAM 持久坏,
    191 个其他 CPU 必然也会读到坏值 => 指向 CPU179 私有读路径(L1D/L2/加载通路)。
(e) DDR 侧有 ECC/GHES/ghes_edac 且固件 first mode 开启, 552s 内零错误记录。
=> 结论: CPU179 读数据通路(私有缓存 SRAM 位阵列/加载-回填数据路径)瞬时多比特
   扰动, 未越过 DRAM ECC 的检测边界(错误未到达 DDR 控制器即已在核内注入/污染)。

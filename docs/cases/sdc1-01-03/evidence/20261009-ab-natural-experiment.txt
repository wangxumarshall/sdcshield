# A-B 自然实验：同款 mesh_upi dwell 的存活日 vs 死亡日对照（2026-10-09 取证）

数据源：`/home/sdc/sdc-excite-reproduce/monitor/monitor.csv`（~80s 采样）
与 `/home/sdc/sdc-excite-reproduce/monitor/pmu_uncore.csv`（l3c 组，~62s 采样，32 切片）。
两窗同文件同列同代码路径对比，列语义以 pmu_uncore.csv header 为准：
$5=back_invalid, $6=retry_ring, $7=retry_cpu, $8=prefetch_drop（均为每采样间隔增量）。

## 1. 热学/功率对照（monitor.csv）

```
10/8 存活窗(09:10-12:00)  n=133  avg cpu1=79.4°C cpu2=55.0°C pw=329W  max cpu1=92°C
10/9 死亡窗(09:15-11:47)  n=110  avg cpu1=77.9°C cpu2=54.5°C pw=324W  max cpu1=79°C
```

**结论：死亡日更凉**（峰值 79°C vs 92°C，均值 -1.5°C，功率 -5W）。
死机不是发生在热学更恶劣的一天 → 削弱"简单热阈值（THERMTRIP 采样可见级）"假说。
（保留：80s 采样看不见亚秒级局部热点。）

## 2. uncore L3C 一致性风暴强度对照（pmu_uncore.csv, group=l3c, 逐切片逐采样均值）

聚合命令（单段干净聚合，可直接复跑）：
```
awk -F',' -v s="<起>" -v e="<止>" '$1>=s && $1<=e && $2=="l3c" {n++; s5+=$5; s6+=$6; s7+=$7; s8+=$8}
  END{printf "n=%d back_invalid=%.1f retry_ring=%.0f retry_cpu=%.0f prefetch_drop=%.0f\n", n, s5/n, s6/n, s7/n, s8/n}' \
  /home/sdc/sdc-excite-reproduce/monitor/pmu_uncore.csv
```

| 窗口 | l3c行数 | back_invalid($5) | retry_ring($6) | retry_cpu($7) | prefetch_drop($8) |
|---|---|---|---|---|---|
| 10/8 存活 mesh dwell | 5280 | 273.5 | 652,291 | 10,243,334 | 9,421,667 |
| 10/9 死亡 mesh dwell | 5024 | 326.2 | 659,917 | 10,311,193 | 9,482,473 |
| 10/4 死亡 openblas dwell | 3712 | 14,395.9 | 416,953 | 1,323,095 | 940,075 |
| 10/6 死亡 openblas dwell | 960 | 23,623.8 | 249,573 | 771,876 | 524,753 |

**结论 1（mesh A-B）**：死亡日与存活日的一致性风暴强度在所有四类 L3C 事件上差异 ≤1.2%
（retry_cpu +0.7%、retry_ring +1.2%、prefetch_drop +0.6%、back_invalid +19% 但绝对值小）。
→ 死亡不由平均风暴强度决定。

**结论 2（跨负载族）**：两次 openblas_dgemm 死亡窗呈**相反画像**——back_invalid 高 ~53 倍
（14.4K/23.6K vs ~0.3K）、retry_cpu 低 ~8-13 倍（1.3M/0.77M vs ~10.3M）。
→ 机器在两类相反的互连负载画像下都死亡：**不存在"某类平均互连事件超阈值"的确定性触发**。

## 3. 推论

触发器不在 80s/62s 粒度可观测的平均量（温度、功率、电压、四类 L3C 事件）里。
存活假说收窄为：(a) 时间/老化随机的硬件失效（概率性，与累计应力相关）；
(b) 亚秒级瞬态事件（电源 di/dt、偶发协议死锁后片上失效保护）——本观测粒度不可见。
两者的判别依赖 ROOT-CAUSE-EXPERIMENT-PLAN.md 的 E1（高频遥测）与 E2/E3（消融）。

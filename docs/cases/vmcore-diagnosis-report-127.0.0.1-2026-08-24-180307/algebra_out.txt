A. 致命崩溃 bio_add_page+0xf0 寄存器闭合验证（dmesg 537462 行）
========================================================================
[A1] FAR 与坏寄存器 x3 的关系
  x3   = 0x553c521da2e9b99f
  FAR  = 0x003c521da2e9b99f
  x3 & 0x00ffffffffffffff = 0x003c521da2e9b99f
  逐字节(x3 LE) = 9f b9 e9 a2 1d 52 3c 55
  逐字节(FAR LE)= 9f b9 e9 a2 1d 52 3c 00
  => FAR 的低 7 字节与 x3 的低 7 字节完全一致，FAR=x3 清零最高字节
  => 崩溃点用的访存地址就是坏寄存器 x3 本身（[x3] 裸解引用）

[A2] sbfm x2,x0,#60,#31 的索引换算（0x937c7c02 人工译码）
  bi_vcnt = 71 (crash: p ((struct bio*)0xffff60401b366738)->bi_vcnt)
  w0 = vcnt-1 = 70
  sbfm x2,x0,#60,#31 = (w0 << 4) & 0xffffffff = 0x0000000000000460 = 1120
  bi_io_vec = 0xffff60401dabd000 (crash 实测)
  bi_io_vec + x2_idx = 0xffff60401dabd460
  现场 x0             = 0xffff60401dabd460
  相等？ True   => x0 == &bi_io_vec[70]（最后一个 bvec）【实锤】

[A3] 装载结果 vs 内存真值（核心闭合等式）
  ldr x3,[x3,x2] 应当读出 bvec[70].bv_page = 0xfffffd012d055b80
  现场 x3（装载结果）               = 0x553c521da2e9b99f
  异或 = 0xaac3af1c8fece21f，不同比特数 = 36/64
  逐字节对比(LE):
    byte0: 真值=80 坏值=9f xor=1f 翻转位=5
    byte1: 真值=5b 坏值=b9 xor=e2 翻转位=4
    byte2: 真值=05 坏值=e9 xor=ec 翻转位=5
    byte3: 真值=2d 坏值=a2 xor=8f 翻转位=5
    byte4: 真值=01 坏值=1d xor=1c 翻转位=3
    byte5: 真值=fd 坏值=52 xor=af 翻转位=6
    byte6: 真值=ff 坏值=3c xor=c3 翻转位=4
    byte7: 真值=ff 坏值=55 xor=aa 翻转位=4
  => 装载结果与内存真值 36/64 位不同，且坏值不落入任何内核地址区间：
     vmemmap 区间?  True (真值在)
     线性映射区?   坏值 0x553c521da2e9b99f 最高字节 0x55 — 不是 ffff 开头的规范内核地址
  => 【实锤】装载通路返回了非内存真值的数据，而该地址在 dump 中内容完好

[A4] 相邻装载（同指令窗口）的正确性对照
  ldr x1,[x1] 读 folio->flags: 现场 x1 = 0x055ffffe0000806b

  ubfm x2,x1,#53,#55 = (x1>>53)&7 = 2  现场 x2 = 2  相等？ True 【实锤】

[A5] 坏值不等于任何现场相关指针（排除'读错位置'假说）
  x3 == folio*(x22)? False
  x3 == bio*(x19)? False
  x3 == bvec地址(x0)? False
  x3 == 真值bv_page? False
  x3 == x1(folio flags)? False
  => 坏值不是任何现场对象的截断/移位/别名，是全新的位串（随机形态）

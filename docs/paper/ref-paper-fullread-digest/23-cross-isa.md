- 核心结论(各带节号/图表号):
  1. **三 ISA 的 SDC 系统比较(§I/§III)**:在 gem5+**GeFIN**(注意:非 gem5-MARVEL——[21] 工具,经组内论文 [9]/[32] 引用)上对 x86/Arm/RISC-V 三架构注入瞬态+永久故障,量化 SDC AVF——L1D/L1I/物理寄存器堆三大 SRAM 阵列 + 功能单元
  2. **抽样方法(§III.A)**:每组件 1,000 次单比特瞬态 + 1,000 次单比特永久(4% 误差/99% 置信,Leveugle 法);**PRF 永久故障 SDC 概率为零,故不列该项**(如实声明)——永久 PRF 故障全数 Crash/掩蔽,无一静默
  3. **瞬态 SDC AVF 三结构排序(§III.B,Fig.1–3)**:PRF 0%–6.9%(Arm)/0%–3.7%(x86)/0.1%–9.9%(RISC-V)——RISC-V 最高、x86 最低;L1I 0.3%–9.9%/0.3%–4.6%/0.2%–5.7%——Arm 最高;L1D 1.2%–43%/0.7%–32.6%/0.8%–40.2%——Arm 最高;**"SDC 在 PRF/L1I 远稀少于 L1D,L1D 上 SDC 是主导故障效果"**——寄存器错值→非法访存、L1I 损坏→非法指令、L1D 损坏→直达程序输出(§III.B 结尾,与 [22] Observation #5 同文)
  4. **永久故障 SDC(§III.C,Fig.4/5)**:L1I 永久 0.1%–2.3%/0.1%–1.3%/0.3%–2.7%(x86 最低/RISC-V 最高);L1D 永久 **5.1%–53.3%(Arm)/4.4%–64.7%(x86)/4.4%–70.8%(RISC-V)**——RISC-V 显著最高;结论:RISC-V 永久故障 SDC 概率显著高于 Arm/x86
  5. **功能单元统计门级模型(§III.D,Fig.6,本篇独有)**:对 FU 建**统计门级故障传播模型**——最简形式为 FU 输出损坏频率(stuck-at-0/1 或 bit-flip);六整数加法器之首(adder #1;地址生成/分支目标计算在独立 FU,脚注 1),输出错误率设 **1/100,000 次操作**、损坏模型 bit-flip;SDC AVF x86 0%–19.2%/RISC-V 0%–30.4%(sha/bitcount 最高;多基准近零)——**但总 AVF 高得多且主要归于 Crash:FU 内微架构与软件掩蔽效应显著低**
  6. **评估方法学谱系(§IV)**:粒子束——系统级 FIT 精确但"粗粒度、不揭示失效根因、设计周期晚期才可用,结果更适合设计验证而非设计决策,晚期芯片修订几乎不可能/代价极高",优势为原生速度;软件级注入——原生速度但"从损坏指令出发而非硬件结构",PVF 须慎用(可误导 AVF 估计,呼应 [17]);FPGA——高吞吐高精度但需完整设计;RTL vs 微架构级——精度与吞吐量成反比,微架构级可早期介入
  7. **结论(§V)**:跨 x86/Arm/RISC-V 的 SDC 风险全景,指导更鲁棒 CPU 架构设计

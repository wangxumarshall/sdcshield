## 核心结论

1. **问题定位(§1)**: FHE(全同态加密)走向实用(加密金融/生物分析/隐私 AI),但其**真实硬件上的可靠性未被研究**;FHE 面临双重不利:① 计算(较明文常超 **10⁴×** 减速)执行时间长 → 瞬态故障概率天然放大;② **损坏更易静默**——服务端无明文访问权,密文呈伪随机,无法判断返回密文是否已损坏(§1);SDC 在高价值隐私域(金融/生物)后果严重。
2. **算法噪声容忍≠硬件噪声容忍(§1)**: 乍看格密码(LWE/RLWE)自带噪声预算,似能吸收扰动;但该容忍**仅限密码学构造约束下的特定形式/分布/量级**;硬件噪声在密文计算的传播中分布与量级均失控——须细粒度检视硬件错误如何穿越密文计算抵达解密结果。
3. ** motivating 实验(§1, Fig.1(b))**: CKKS 加密神经网络做乳腺癌二分类(Breast Cancer Wisconsin 数据集),注入单比特瞬态故障:明文推理仅轻度退化(95.6→89.1),密文推理**断崖式跌落(95.6→50.9)**——FHE 计算对瞬态故障本质不容忍。
4. **算子级注入(§3.2)**: 5 个最基础同态算子(ct-pt mult / ct-ct mult / ct-pt add / ct-ct add / ct rot)× 4 组参数(SET1–4:乘法深度 L=2/4/6/8,密文维 N=32768,模数 Q=180/280/380/480 bit,缩放因子 Δ=50 bit);OpenFHE 实现,Intel Xeon Platinum 8358P,Pin 注入指令流单比特翻转,每算子 10,000 次单错运行——**约 22% 的单比特故障导致 SDC**;SDC 较崩溃更严重(无任何可观测症状)。
5. **偏差量级与模数强相关(§3.2, Fig.3(b))**: SDC 一旦发生,**解密消息的每个 slot 几乎都大偏差**;最大偏差随 Q 单调增长:Q 从 180→480 bit,slot 误差上界从 ~10³⁵ → ~10¹²⁵(**每增加 100 bit 模数约扩大 10³⁰**);乘法类算子偏差小于加法/旋转——乘法触发 rescale 消耗部分密文模数,削弱后续放大空间。
6. **多项式级深入(§3.3, Fig.4)**: KeySwitch(同为 HMult/HRot 核心步骤,**占整体运行时 >90%**)的 7 个多项式步骤(intt/bconv/ntt/point-mult/intt/bconv/ntt)全部 SDC 率 **>20%**;偏差量级同样与 Q 强相关——FHE 流水线**每一步**都高脆弱。
7. **容错算法评估(§4)**: 两种经典策略——① **冗余 DMR**(双模冗余执行+比对,失配重执行);② **校验和 ABFT**(明言"未设计新 ABFT 方案,集成改造矩阵乘/FFT-NTT/RNS 算术的既有方法"——如 NTT 线性不变量 Flag_in/Flag_out 校验 + 输入输出重载检测 load/store 故障);4 个负载(VV 向量乘/MV 矩阵向量乘/Rot 旋转/House 加州房价回归),SET3 参数,每负载 50,000 次单错注入。
8. **端到端结果(§4.3, Fig.5)**: 无保护 SDC 率 **19.89%–22.24%**;DMR 降至 **<0.1%**,校验和方法达到**相当防护水平**;开销: DMR ≈ **1× 减速**(总量约翻倍),校验和仅 **13–16%(约 15%)**——在 FHE 本已巨大的性能税(10⁴×)上,15% 已不菲,更轻量的 SDC 容错是未来方向(§4.4)。
9. **理论机制(§5 总结)**: 小扰动经 **slot 级扩散 + 全模数误差增长**被结构性放大——FHE 对 SDC 脆弱性的算法级根因。
10. **结论与未来(§5)**: CKKS 评估的每一步都需可靠保护;未来做轻量、硬件感知的 FHE 容错,联合优化可靠性与性能;呼吁关注隐私计算在真实硬件上的可靠性。

## 分类学标注

- **根因机理**: 采信标准瞬态故障画像(软错误/制造缺陷/设计逃逸 [18]);**FHE 特有放大机制**——执行时间放大(10⁴×→故障概率↑)与结构放大(slot 扩散+全模数增长)双层。
- **故障模式**: 指令流单比特瞬态翻转 → 密文损坏 → 解密后全 slot 大偏差(指数级爆到 10³⁵–10¹²⁵);**"双重静默"**: 系统级无异常 + 服务端无明文参照(密文伪随机不可判)——SDC 静默性被加密计算算法性放大,是 SDC 核心特征在密码学域的新形态。
- **检测技术**: ABFT 校验和(NTT 线性不变量,13–16% 开销);DMR 比对(检测+重执行)。
- **处理技术**: DMR 重执行纠正(检出失配即重算);ABFT 检测——检测后处置沿用经典重执行路径。
- **生命周期**: 部署/运行期(密文计算阶段注入,解密无错假设下评估);栈层级: **密码学/隐私计算应用层**——53 篇中首个 FHE 栈层样本,SDC 影响面扩展到加密基础设施。
- **负载特性**: FHE 管线**静态、数据无关、控制流无关**——结构上适合线性不变量校验(ABFT 可行的原因)。

## 方法论要点

1. **单错最小扰动模型**: 每次执行至多一个瞬态故障——刻画传播行为的干净基线,与 [22] Sangchoolie"one bit is not enough"的多比特扩展互补。
2. **层级解剖式注入**: 算子层(5 算子)→ 多项式层(KeySwitch 7 步)——从粗到细定位脆弱点,而非只做端到端黑盒。
3. **参数扫描**: L/Q 四档扫描分离"算法参数→偏差量级"的定量关系(10³⁰/100bit)——把 SDC 严重度与密码学参数联系起来,跨社区的方法论嫁接。
4. **诚实边界**: 明言未设计新 ABFT(集成既有方案);单错模型、只注计算阶段(解密假设无错)的假设显式声明。
5. **机制解释配对现象**: 乘法偏差小于加法 ← rescale 消耗模数——现象背后给出算法级解释,不止于统计。
6. **商用 COTS 平台**: Xeon 8358P + Pin 指令级注入——无需专用 FI 硬件,方法可复现。

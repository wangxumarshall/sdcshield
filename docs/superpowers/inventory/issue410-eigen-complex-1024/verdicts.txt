## 2. 布局探针（ptranspose 置换的直接机械证明, O3, --max_faults 0）

命令形: gem5.opt --quiet --outdir=... configs/se/arm_chaos.py --cpu O3 \
  --max_faults 0 --cmd workloads/sdcshield/eigen_ptranspose_layout_probe_vl<t> \
  --sve_vl <qw>;  qw: 128=1 256=2 512=4 1024=8

  vl=128 (NC=1): PASS cols4 混合打包==标量布局; SKIP 方阵转置(N=1 通用 no-op)
  vl=256 (NC=2): PASS cols4; PASS 方阵 out[q][m]==in[m][q]
  vl=512 (NC=4): PASS cols4; PASS 方阵
  vl=1024 (NC=8): PASS cols4 (N=4<NC=8 越界形状, 修复核心); PASS 方阵 (N=NC=8)
  四档 SDCSHIELD_FAILS=0, rc=0
本机 (SVE-256 硅件) vl256/vl128 探针同样 PASS（先行快速验证）。

## 7. golden 语义

svd_cvd 的 golden 是 per-thread same-source; 双 kernel 通道 A（同矩阵两次
求解 byte 比对）+ 各档 SDCSHIELD_FAILS=0 即 golden 一致性证明;
通道 C 补数学正确性（vs 标量语义的重构/酉性, 1e-14 量级）。

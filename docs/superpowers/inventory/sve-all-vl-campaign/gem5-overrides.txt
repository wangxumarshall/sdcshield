# 标定依据（详见 triage-512.md 标定表）：gem5 nofork 下 -t 时限预算被 shmem
# 叠印结构性禁用（inner_loop_count ↔ current_test_endtime 碰撞，DWARF 实测），
# 每测试恰执行 ~1 轮内层循环——单轮成本 = 测试的整轮工作量。因此降容的
# 语义是"把那一轮压进 30 min 投影阈值内"，与 native 腿"把 300s 预算内的
# 迭代几何压小"不同源但同机制（几何 knob）。
sleef_sve|-O sleef_sve.nelems=1048576
# eigen_svd_cdouble_sve: mdim 的 clamp 下限即 300（svd_cdouble_sve.cpp:97
# MDIM_MIN），任何更低 -O 都被静默钳回——不设 override，改用长超时单独
# 重跑收格（见 triage-512.md §5.2）。
# acl_gemm_sve: golden 为 naive 标量三重循环（dim³ 次 std::fmaf），dim=256
# 单轮 >60 min 超时（实测）→ 降到 128（(128/256)³=1/8）。dim 下限 64。
acl_gemm_sve|-O acl_gemm_sve.dim=128
# fisttp_sve: num_elements 自适应在 2 GiB guest 上放大到单轮 >60 min →
# 收到 clamp 下限 1024。
fisttp_sve|-O fisttp_sve.num_elements=1024
# eigen_gemm_double_max_arm: 自适应 dim 在 2 GiB guest 上取值过大超时 →

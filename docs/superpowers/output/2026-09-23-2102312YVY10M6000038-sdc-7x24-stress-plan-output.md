| `-q` | 种子行 0 条（默认 4462 条） | **弃用**（取证必需） |
| `--max-messages=50` | 体量几乎不减 | result 行豁免，无效 |
| YAML gzip | 2.15MB→178KB（12×） | 每日压缩方案 |

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以当前源码(含 3 个未合入主干的 sve512 `_svd` 测试 + origin/main 最新生成器)构建 openEuler-22.03LTS 的 sdcshield 二进制,full 级纯净容器验证通过后提交并推送 22.03 submodule 及主仓分支指针。

**Architecture:** 纯构建任务,零源码改动。三个前置状态问题必须先解决:(1) 当前分支的 `package-built-artifacts.sh` 是旧版生成器(无 `full` 选项),直接构建会回退远端 0813962 给 `run-sdcshield.sh` 加的 full 功能;(2) 22.03 submodule 远端 main 已前进到 0813962,不先对齐则产物提交无法快进推送;(3) 源码自上次构建基准 b61213e 后已变(3 个新测试文件),BUILD-HASH 必然失配,`build-all.sh` 会走完整重建路径。解法:新建 chore 分支 → 合入 origin/main(已预演零冲突)→ 同步 submodule 工作树 → `build-all.sh 22.03 LTS --full` → 产物核验 → submodule 快进推送 + 主仓分支推送。

**Tech Stack:** git/submodule、podman 离线构建容器(`localhost/openeuler-offline:22.03-LTS`,已在本地)、`scripts/offline-build/build-all.sh` 编排器(镜像幂等 skip → 哈希判定 → container-build → package → full 验证闸门)。

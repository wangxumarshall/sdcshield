> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在本机（裸金属 TaiShan 2280，128 核 Kunpeng 920）构建并启动 7×24 不间断、全核覆盖的 SDC 激发与检测战役，产出一套参数化、可在新单板零修改复用的方案与运行结果。

- **参数零硬编码**：核数/内存/Tjmax/路径/用例名全部来自画像或运行时探测；禁止在脚本中写死 128、32GB、105°C、用例名假设（指令文档 §8.4 复用性验收）。

- **背景服务共存**：llama-server/qemu/TDengine/piper 全部保留（用户决策）；逐核隔离结果标注共存噪声；大矩阵档位按共存内存预算收紧。

- **One patch per unit**：每个 Task 一个 commit；commit 前必须跑完该 Task 的验证命令并引用真实输出；commit message 不带 Co-Authored-By 尾注；自动 push 到远端（非 main）。

## §4 L0–L5 战役设计（精确命令）

> 以下为 full 模式形态；smoke 模式同一代码路径、时长参数缩小（见 Task 6）。`$BIN`=builddir/sdcshield；YAML 日志按阶段/档位分文件。公共标志：`-n 0 --on-crash=context --ignore-timeout --ignore-os-errors --retest-on-failure=3 --temperature-threshold=<pause_milli>`（全部 feature-detect，缺失自动去除）。

**L0 冒烟（每次变更后，~10min）**
```bash
$BIN --list-tests | tee l0_list.txt          # 数量与 README 基准核对
$BIN -e zstd19 -n 1 -t 2000 -o l0_zstd.yaml  # 必须 pass
$BIN -e <每域代表> -t 60s -o l0_rep.yaml      # memcopy/cache/atomic/fma/gemm/超越/fft/压缩/密码 各 1
$BIN --dump-cpu-info > l0_cpuinfo.txt
```
判据：list 数量 ≥ 278（PROD）；zstd19 `result: pass`；代表用例无 crash。

**L1 单组件基线（首轮 + 每周期冷机窗口，30m/周期首轮 2–4h 首次）**
逐检测域单独跑（全核，90s/用例），建立 runnable/skip 台账（哪些用例本机 skip 及原因，如 SVE 类）。

**L2 谱系扫档（每 24h 周期首轮，~3h）** — 复用 `scripts/run/run_sdc_spectrum.sh`（已通读：1a GEMM mdim 64/256/512/1024 → 1b transab 0–3+β=500 → 1c sleef nelems 1024/16384/262144 → 1d FFT n 4096/4099/6144/10000 → 1e igzip level 0–3 → 1f crypto/LU/mixed → 阶段2 mini-dwell），战役驱动追加：
```bash
# 1g: ipsec 数据路径谱系（代表子集 × datasize 1024/64K/16M）
for ds in 1024 65536 16777216; do $BIN -e <ipsec代表> -O <test>.datasize=$ds -t 15m -o l2_ipsec_ds$ds.yaml; done
# 1h: memcpy_rewr 三策略（跨 NUMA / 同 die L3 对打 / 目录失效风暴）
for s in 0 1 2; do SANDSTONE_STRATEGY_INDEX=$s $BIN -e memcpy_rewr -t 15m -o l2_memcpy_s$s.yaml; done
```

**L3 多样性轮转（日间主力，8h：固定序 6h + 随机序 2h）** — 用**全部 PROD 用例**（多样性最大化的实现方式，指令文档示例套件的超集）：
```bash
timeout 6h $BIN -T forever -t 60s --disable eigen_svd_double,eigen_sparse <公共标志> -o l3_fixed_cN.yaml
timeout 2h $BIN -T forever -t 60s --disable eigen_svd_double,eigen_sparse --test-list-randomize <公共标志> -o l3_rand_cN.yaml
# eigen ULP 敏感类单线程补跑（CLAUDE.md 已知多线程数值噪声，防假阳性）
$BIN -e 'eigen*' -n 1 -t 300s -o l3_eigen_n1.yaml
```
`--disable` 名单来自 L1 台账（本机实际会引发多线程数值噪声的 eigen 用例）。

**L4 深驻留（夜间，动态填充至次日 07:30）** — `--max-test-loop-count=0` 关 fracturing，单模式持续暴露：
```bash
# 驻留列表 = 本周期事件涉及的测试优先，否则默认 top：
# openblas_dgemm(默认 mdim256) sleef_neon pocketfft_fft isal_igzip openssl_sha
for t in <dwell_list>; do $BIN -e $t -t 2h --max-test-loop-count=0 <公共标志> -o l4_dwell_$t.yaml; done
```

**L5 专项激发（每日 90m，四项轮换）**
- **di/dt 阶跃**：governor `powersave↔performance` 阶跃（经 root 监控服务 cmd 文件代理）× 6 轮，每轮空载 30s + power-virus 类突发 5m（BETA `--quality=0`，feature-detect `power_virus*,arm64_sdc`，本机不存在则回退 `fma*,cachebounce`）；
- **热激发**：全核 dgemm+cachebounce 预热至 CPU ≥85°C（上限 30min）→ 立即跑目标用例 30min，记录温度带；
- **跨 NUMA/互联**：memcpy_rewr 三策略（短档）+ 大 mdim 档（内存预算守卫：`-n 64` + mdim 2048 需 scratch 6.4GB×2 裕量，MemAvailable 不足则降档并记录）；
- **逐 L3 域隔离**：`--cpuset=p0/p1/p2/p3` 各 30m 高检出套件（同计算跨域交叉比对；命中后二分到核属分诊流程）。

**补充检测层（全程）**：stress-ng `--verify`（小时轮转：matrix/vecrot/qsort/search/opcode/longops/float，`taskset` 到派生保留核，nice 低优先级，启动时对照 `stress-ng --verifiable` 过滤）+ rasdaemon（已在运行）+ 监控时序（下）。

## §6 安全联锁（root 监控服务执行，60s 周期）

| 触发 | 动作 | 恢复 |
|---|---|---|
| CPU Core Rem（两 socket 取 max）≥ **95°C** | 写 PAUSE 标志退载 + 告警 | ≤90°C 自动恢复（仅热联锁自愈） |
| FAN2/FAN3 无读数或 0 RPM | PAUSE + 告警 | 读数恢复 3 个连续采样后自愈 |
| SEL 新增 **Critical** Asserted | PAUSE（**粘性**，需人工清除）+ 事件快照 | 人工 `rm PAUSE` |
| 磁盘 ≥85% / ≥95% | 告警 / PAUSE 停新日志 | 人工清理后恢复 |
| MemAvailable < 2GB | PAUSE（防 OOM，共存服务保护） | >4GB 自愈 |
| BMC 通道连续 10 次失败 | 告警降级为 OS 侧采样（acpitz/meminfo/df 不断链） | BMC 恢复自动切回 |

双保险：驱动进程内 `--temperature-threshold=<pause_milli>`（sdcshield 原生热联锁，行为在 L0 冒烟验证）。**禁止**为压出问题拆温度保护/关节流。

## §7 SDC 命中后的取证、复测与分诊（普查模式，战役不中断）

1. **即时取证（自动，驱动内 `handle_failure`）**：事件目录 `events/<时间戳>-<label>-rc<N>/`：完整 YAML 日志（含种子/核位/knob）、失败行摘录、monitor.csv ±5min 工况切片、EDAC 计数、free/load；`snapshot.request` → root 服务 60s 内补 dmesg/SEL/SDR/DCMI 快照。
2. **可复现性判定（自动）**：原命令复测 ×3（若 YAML 可提取种子则 `-s <seed>` 种子重放，否则同命令重放并注明）；冷/热两态各覆盖（复测延后到下一冷机窗口补做一次，记台账）。
3. **逐核定位（半自动，命中后人工触发）**：`--cpuset` 对相关 NUMA 域二分 → 定位到逻辑核/物理核/域；再全核同载验证"他核效应"。
4. **CPU vs 内存归因**：缓存驻留档（mdim=64/256、nelems 小足迹）重放仍错=核内；仅大足迹/DRAM 档错=结合 EDAC/内存基线排查内存路径；仅多核对打错=一致性/互联方向；证据不足标"待判定"。
5. **台账**：`events/ledger.csv`（时间、label、rc、复测结果、目录）+ 仓库 `docs/superpowers/output/...-output.md` 同步。
6. crash/abort/超时同流程（SDC 与崩溃可同源）。

```bash
# collect_inventory.sh — 幂等软硬件画像采集（新单板入口）

#!/usr/bin/env python3
import os, pty, sys, select, time
PW = os.environ['SDC_ROOT_PW']
def su_run(cmd, timeout=120):
    pid, fd = pty.fork()
    if pid == 0:
        os.execvp('su', ['su', 'root', '-c', cmd]); os._exit(127)
    out=b''; sent=False; end=time.time()+timeout
    while time.time() < end:
        r,_,_=select.select([fd],[],[],0.5)
        if r:
            try: d=os.read(fd,65536)
            except OSError: break
            if not d: break
            out+=d
        if not sent and (b'assword' in out or '密码'.encode() in out):
            os.write(fd,(PW+'\n').encode()); sent=True
    try: os.close(fd)
    except OSError: pass
    try: os.waitpid(pid,0)
    except ChildProcessError: pass
    return out
sys.stdout.write(su_run(sys.argv[1], int(sys.argv[2]) if len(sys.argv)>2 else 120)
                 .decode('utf-8','replace').replace(PW,'<REDACTED>'))

runc "$OUT/04_ipmitool_dcmi_power.txt" ipmitool dcmi power reading
```

- [ ] **Step 1: 写 sdc_monitor.sh**

```bash
#!/bin/bash
# sdc_monitor.sh — 以 root 运行（sdc-monitor.service）。
# 每 60s：IPMI+OS 采样入 CSV + 安全联锁；每 5min：SEL 增量检查；处理 cmd/ 命令文件。
set -u
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
source "$SCRIPT_DIR/sdc_common.sh"
ensure_dirs
[ -f "$CAMPAIGN_DIR/campaign.env" ] && source "$CAMPAIGN_DIR/campaign.env"
PAUSE_C="${THERMAL_PAUSE_C:-95}"; RESUME_C="${THERMAL_RESUME_C:-90}"
DISK_WARN="${DISK_WARN_PCT:-85}"; DISK_STOP="${DISK_STOP_PCT:-95}"
CSV="$MON_DIR/monitor.csv"; SNAP="$MON_DIR/snapshots"; SEL_EV="$MON_DIR/sel_events"
mkdir -p "$SNAP" "$SEL_EV"
[ -f "$CSV" ] || echo "ts,cpu1_c,cpu2_c,mem1_c,mem2_c,outlet_c,inlet_c,watts,vddavs1,vddavs2,fan2_rpm,fan3_rpm,prochot1,prochot2,tz0_c,tz1_c,memavail_kb,load1,disk_pct,bmc_ok" > "$CSV"
sdr_val() { awk -F'|' -v s="$1" '$1 ~ s {print $5}' <<<"$SDR" | grep -oE '[0-9]+(\.[0-9]+)?' | head -1; }
last_sel_id=""; sel_tick=0; bmc_fail=0; thermal_paused=0; fan_bad=0; mem_paused=0
paused_for() { [ -f "$PAUSE_FLAG" ] && grep -q "$1" "$PAUSE_FLAG" 2>/dev/null; }
set_pause() { echo "$2 ($(date '+%F %T'))" > "$PAUSE_FLAG"; alert "PAUSE: $2"; }
clr_pause_if() { if paused_for "$1"; then rm -f "$PAUSE_FLAG"; alert "RESUME: $1 已恢复"; fi; }
while :; do
  ts=$(date '+%F %T')
  SDR=$(timeout 20 ipmitool sdr list 2>/dev/null); bmc=$([ -n "$SDR" ] && echo 1 || echo 0)
  [ "$bmc" = 0 ] && bmc_fail=$((bmc_fail+1)) || bmc_fail=0
  [ $bmc_fail -ge 10 ] && { alert "BMC 通道连续失败 ${bmc_fail} 次，降级 OS 侧采样"; }
  c1=$(sdr_val 'CPU1 Core Rem'); c2=$(sdr_val 'CPU2 Core Rem')
  m1=$(sdr_val 'CPU1 MEM Temp'); m2=$(sdr_val 'CPU2 MEM Temp')
  ot=$(sdr_val 'Outlet Temp');  in_=$(sdr_val 'Inlet Temp')
  pw=$(sdr_val '^Power ');     v1=$(sdr_val 'CPU1 VDDAVS'); v2=$(sdr_val 'CPU2 VDDAVS')
  f2=$(sdr_val 'FAN2 Speed');  f3=$(sdr_val 'FAN3 Speed')
  p1=$(awk -F'|' '$1 ~ "CPU1 Prochot"{print $2}' <<<"$SDR" | tr -d ' ')
  p2=$(awk -F'|' '$1 ~ "CPU2 Prochot"{print $2}' <<<"$SDR" | tr -d ' ')
  tz0=$(awk '{printf "%.1f",$1/1000}' /sys/class/thermal/thermal_zone0/temp 2>/dev/null)
  tz1=$(awk '{printf "%.1f",$1/1000}' /sys/class/thermal/thermal_zone1/temp 2>/dev/null)
  ma=$(awk '/MemAvailable/{print $2}' /proc/meminfo)
  l1=$(awk '{print $1}' /proc/loadavg)
  dp=$(df -P "$CAMPAIGN_DIR" | awk 'NR==2{gsub(/%/,"");print $5}')
  echo "$ts,${c1:-}, ${c2:-},${m1:-},${m2:-},${ot:-},${in_:-},${pw:-},${v1:-},${v2:-},${f2:-},${f3:-},${p1:-},${p2:-},${tz0:-},${tz1:-},${ma:-},${l1:-},${dp:-},$bmc" >> "$CSV"
  # ---- 温度联锁（双 socket 取 max，滞回）----
  maxt=0; for t in "$c1" "$c2"; do [ -n "$t" ] && [ "$t" -gt "$maxt" ] 2>/dev/null && maxt=$t; done
  if [ "$maxt" -ge "$PAUSE_C" ] 2>/dev/null; then
    if ! paused_for thermal; then set_pause thermal "CPU ${maxt}C >= ${PAUSE_C}C"; fi; thermal_paused=1
  elif [ "$thermal_paused" = 1 ] && [ "$maxt" -le "$RESUME_C" ] 2>/dev/null; then
    clr_pause_if thermal; thermal_paused=0
  fi
  # ---- 风扇联锁（FAN2/3 任一无读数即暂停；连续 3 次恢复才放行）----
  if [ "$bmc" = 1 ]; then
    if [ -z "$f2" ] || [ -z "$f3" ] || [ "$f2" = 0 ] || [ "$f3" = 0 ]; then
      if [ "$fan_bad" -lt 3 ]; then fan_bad=$((fan_bad+1));
        [ "$fan_bad" = 3 ] && ! paused_for fan && set_pause fan "FAN2=${f2:-na} FAN3=${f3:-na}"; fi
    else fan_bad=0; clr_pause_if fan; fi
  fi
  # ---- 内存联锁（防 OOM：与背景服务共存保护）----
  if [ -n "$ma" ] && [ "$ma" -lt 2097152 ] 2>/dev/null; then
    ! paused_for mem && set_pause mem "MemAvailable ${ma}kB < 2GB"
  elif [ -n "$ma" ] && [ "$ma" -gt 4194304 ] 2>/dev/null; then clr_pause_if mem; fi
  # ---- 磁盘水位 ----
  [ -n "$dp" ] && [ "$dp" -ge "$DISK_STOP" ] 2>/dev/null && { ! paused_for disk && set_pause disk "disk ${dp}% >= ${DISK_STOP}%"; }
  [ -n "$dp" ] && [ "$dp" -ge "$DISK_WARN" ] && [ "$dp" -lt "$DISK_STOP" ] 2>/dev/null && [ $(( $(date +%s) % 3600 )) -lt 60 ] && alert "磁盘水位 ${dp}%"
  # ---- SEL 增量（每 5min；Critical Asserted = 粘性暂停）----
  sel_tick=$((sel_tick+1))
  if [ $((sel_tick % 5)) -eq 1 ]; then
    selout=$(timeout 20 ipmitool sel list 2>/dev/null)
    if [ -n "$selout" ]; then
      lastid=$(tail -1 <<<"$selout" | awk -F'|' '{gsub(/ /,"",$1)}')
      if [ -n "$last_sel_id" ] && [ "$lastid" != "$last_sel_id" ]; then
        awk -F'|' -v a="$last_sel_id" '{gsub(/ /,"",$1); if (strtonum("0x"$1) > strtonum("0x"a)) print}' <<<"$selout" > "$SEL_EV/$(date +%Y%m%d-%H%M%S).txt"
        grep -qE 'Critical.*(Asserted)' "$SEL_EV/"*.txt 2>/dev/null && { ! paused_for sel && set_pause sel "SEL Critical 事件（粘性，需人工 rm PAUSE）"; }
      fi
      last_sel_id=$lastid
    fi
  fi
  # ---- 命令文件：governor 代理（L5 di/dt 用）----
  if [ -f "$CMD_DIR/governor.request" ]; then
    g=$(cat "$CMD_DIR/governor.request")
    for c in /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor; do echo "$g" > "$c" 2>/dev/null; done
    mv "$CMD_DIR/governor.request" "$CMD_DIR/governor.done.$(date +%s)"
  fi
  # ---- 命令文件：root 取证快照（事件流水线用）----
  if [ -f "$CMD_DIR/snapshot.request" ]; then
    sd="$SNAP/$(date +%Y%m%d-%H%M%S)"; mkdir -p "$sd"; chmod 755 "$SNAP" "$sd"
    timeout 30 ipmitool sdr list > "$sd/sdr.txt" 2>&1
    timeout 30 ipmitool sel list > "$sd/sel.txt" 2>&1
    timeout 30 ipmitool dcmi power reading > "$sd/dcmi.txt" 2>&1
    dmesg > "$sd/dmesg.txt" 2>&1
    mv "$CMD_DIR/snapshot.request" "$CMD_DIR/snapshot.done.$(date +%s)"
  fi
  sleep 60
done
```

```bash
run_sdc() {  # run_sdc <label> <phase_timeout_s|0> <sdcshield args...>（-o 自动加）
  local label="$1" pto="$2"; shift 2
  check_pause
  local ts yaml out; ts=$(date +%H%M%S)
  local day=$(date +%F | tr -d -); mkdir -p "$LOG_ROOT/$day"
  yaml="$LOG_ROOT/$day/${ts}-${label}.yaml"; out="$LOG_ROOT/$day/${ts}-${label}.out"
  state_set phase "$label"; state_set phase_cmd "$BIN $*"
  if [ "$pto" -gt 0 ]; then
    timeout --signal=TERM --kill-after=90s "$pto" "$BIN" "$@" -o "$yaml" > "$out" 2>&1
  else
    "$BIN" "$@" -o "$yaml" > "$out" 2>&1
  fi
  local rc=$?
  [ $rc -eq 124 ] && log "$label 达到阶段时长（正常切换）"
  if grep -q 'result: *fail' "$yaml" 2>/dev/null || { [ $rc -ne 0 ] && [ $rc -ne 124 ]; }; then
    handle_failure "$label" "$yaml" "$rc" "$*"
  fi
  return 0
}
handle_failure() {  # 取证 + 复测×3 + 台账（普查模式：不中断）
  local label="$1" yaml="$2" rc="$3"; shift 3; local cmd="$*"
  local evdir="$EVENTS_DIR/$(date +%Y%m%d-%H%M%S)-${label}-rc${rc}"; mkdir -p "$evdir"
  cp "$yaml" "$evdir/" 2>/dev/null
  local seed; seed=$(grep -oiE '(seed|rng[-_ ]state)[^0-9]*[0-9]+' "$yaml" 2>/dev/null | head -1 | grep -oE '[0-9]+$')
  { echo "cmd: $BIN $cmd"; echo "rc: $rc  date: $(date -Is)  seed_extracted: ${seed:-none}"
    echo "--- 失败行 ---"; grep -E 'result: *fail|exit: *fail' "$yaml" 2>/dev/null | head -20
    echo "--- monitor 最近 20 行 ---"; tail -20 "$MON_DIR/monitor.csv" 2>/dev/null
    echo "--- EDAC ---"; cat /sys/devices/system/edac/mc/mc*/ce_count /sys/devices/system/edac/mc/mc*/ue_count 2>/dev/null
    echo "--- mem ---"; free -h; } > "$evdir/context.txt"
  touch "$CMD_DIR/snapshot.request"   # root 服务 60s 内补 dmesg/SEL/SDR 快照到 monitor/snapshots/
  local i rcf; : > "$evdir/retests.txt"
  for i in 1 2 3; do
    sleep 5; check_pause
    if [ -n "$seed" ] && has --rng-state; then
      "$BIN" $cmd -s "$seed" -o "$evdir/retest$i.yaml" > "$evdir/retest$i.out" 2>&1; rcf=$?
    else
      "$BIN" $cmd -o "$evdir/retest$i.yaml" > "$evdir/retest$i.out" 2>&1; rcf=$?
    fi
    echo "retest$i(seed=${seed:-cmd}) rc=$rcf fail_lines=$(grep -c 'result: *fail' "$evdir/retest$i.yaml" 2>/dev/null)" >> "$evdir/retests.txt"
  done
  echo "$(date '+%F %T'),$label,rc=$rc,seed=${seed:-cmd},$(cat "$evdir/retests.txt" | tr '\n' ';'),$evdir" >> "$EVENTS_DIR/ledger.csv"
  alert "SDC/崩溃事件: $label rc=$rc → $evdir（战役继续）"
  DWELL_OVERRIDE=$(resolve "$label" | head -c 200)   # 本周期 L4 优先复现该测试
}
```

```bash
#!/bin/bash
# install.sh — 以 root 运行：安装 systemd 单元 + logrotate（模板替换，新单板通用）
set -eu
HERE="$(cd "$(dirname "$0")" && pwd)"
REPO="$(cd "$HERE/../.." && pwd)"
RUN_USER="${SDC_USER:-$(stat -c %U "$REPO")}"
CAMPAIGN_DIR="${1:-/home/$RUN_USER/sdc-campaign}"
sed_inplace() { sed "s|@REPO@|$REPO|g; s|@CAMPAIGN_DIR@|$CAMPAIGN_DIR|g; s|@USER@|$RUN_USER|g" "$1" > "$2"; }
sed_inplace "$HERE/systemd/sdc-campaign.service.in" /etc/systemd/system/sdc-campaign.service
sed_inplace "$HERE/systemd/sdc-monitor.service.in"  /etc/systemd/system/sdc-monitor.service
sed "s|@CAMPAIGN_DIR@|$CAMPAIGN_DIR|g" "$HERE/logrotate/sdc-campaign" > /etc/logrotate.d/sdc-campaign
mkdir -p "$CAMPAIGN_DIR" && chown "$RUN_USER" "$CAMPAIGN_DIR"
systemctl daemon-reload
systemctl enable sdc-monitor.service sdc-campaign.service
echo "安装完成: REPO=$REPO CAMPAIGN_DIR=$CAMPAIGN_DIR USER=$RUN_USER"
echo "启动: systemctl start sdc-monitor sdc-campaign（或 scripts/campaign/start.sh）"
```

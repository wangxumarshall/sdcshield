## 1. 背景与目标

撰写一份**以分类学为骨架的 SDC(静默数据损坏)学科综述报告**(survey 体),覆盖三个层次:

- **对象层**:SDC 核心特征(定义边界、静默性根源、与 crash/DUE/masked 的区分)、**根因机理分类**(物理根因→电路表现→微架构部位的因果链)、**故障模式分类**(位分布/单多位/一致性/频率特征/触发条件);
- **对策层**:**检测技术分类学**(原理×栈层×生命周期阶段)、**处理技术分类学**(容错/纠错/隔离/调度),每章末规律小结(共识/分歧/适用条件);
- **两界层**:学术界与产业界各维度总结、规律与观点对比、演进趋势(2003–2026)、**每篇论文的企业合作关系**(通过作者机构/致谢章节/资助声明提取)。

### 3.4 执行纪律

- **主会话直读**(方案 A 已确认):Read 工具按页读 PDF,单次 ≤20 页。
- **落盘节奏**:每批(R1–R8)读完 → 笔记全部落盘 + INDEX.md 更新进度 → commit。批内如上下文吃紧,读 3–4 篇即先行落盘该几篇。
- **git**:feature 分支(自 `main` 切出,如 `research/survey-fullread-20260928`);每批一个 commit(`git commit -s`,签名行 `Signed-off-by: wangxu <wangxumarshall@qq.com>`,末行,无 Co-Authored-By);commit 前自查笔记无占位符;push 到 feature 分支,不碰 main。
- **上下文管理**:笔记是唯一可信载体,PDF 原文内容不依赖记忆;每批 commit 后 progress-log 可记恢复点(可选)。

### 3.5 诚实纪律(全阶段适用)

- 每条企业合作信息必须带**证据分级 + PDF 页码**;无致谢/无资助声明的明确写"原文无……"。
- 每个关键数字标注**论文 + 节/图表号**;读不到的信息明确写"原文未给出"。
- 不从文件名推断结论;论文身份以 PDF 页脚核实。
- 工业文档标注类型,不冒充同行评审结论。
